# All-Electric Passenger Aircraft — Conceptual Design Report

This repository contains our university team project report titled **“Tam Elektrikli Yolcu Taşıma Hava Aracı”** (All-Electric Passenger Transport Aircraft).

## What’s inside
- **Full report (PDF):** `docs/electric-aircraft-report.pdf`

## Scope / Highlights
- Mission profile definition (hover / take-off / climb / cruise / descent / landing) and segment-based evaluation
- Conceptual sizing and feasibility checks for an all-electric configuration
- Weight estimation, iteration and convergence approach (W0 estimation)
- Requirements & constraints discussion and design trade-offs
